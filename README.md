1️⃣ What is the difference between var, let, and const?

Ans: var = function scoped, re-declare and global variable.
let = Block Scoped, re-Assigned, re-declare not allow.
const = Block scoped, re-Assigned and re-declare not allow. just value changed.

2️⃣ What is the spread operator (...)?

Ans: The spread operator does copy/expand arrays and object properties.

3️⃣ What is the difference between map(), filter(), and forEach()?

Ans: map(): return new Array.
fillter(): Selects elements according to condition and returns a new array.
forEach(): Only do loop, return nothing.

4️⃣ What is an arrow function?

Ans:Modern way to write functions with short syntax.
const sum = (a,b) => a + b;

5️⃣ What are template literals?

Ans: You can use a backtick (``) to write a string and insert the dynamic variable.

let name = "Fahim"
console.log(`Hello ${name}`)
